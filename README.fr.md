### Démarche d'ingénierie

```text
Besoin
    ↓
Architecture / Documentation
    ↓
Petite tranche verticale
    ↓
Implémentation
    ↓
Tests automatisés
    ↓
Validation native
    ↓
Revue indépendante
    ↓
Pull Request
    ↓
Intégration
```

F7Hub est développé avec des frontières d'architecture explicites, des tranches de fonctionnalités ciblées, un contrôle de changement basé sur Git, des tests de régression, une documentation technique et une implémentation assistée par IA sous contraintes d'ingénierie définies.

## Ingénierie assistée par IA

J'utilise les agents d'IA de programmation comme des outils d'ingénierie, pas comme un remplacement de l'architecture, de la validation ou du jugement technique.

Ma méthode de travail met l'accent sur :

- des exigences et un périmètre clairs
- l'architecture avant l'implémentation
- des changements petits et révisables
- des tests de régression automatisés
- la validation native lorsque pertinent
- la revue indépendante
- les branches Git et les pull requests
- une documentation synchronisée avec l'implémentation

Le code généré par IA demeure soumis aux mêmes standards de revue et de validation que toute autre implémentation.
