## AI-Assisted Engineering

I use AI coding agents as engineering tools, not as a replacement for architecture, validation, or technical judgment.

My workflow emphasizes:

- clear requirements and scope
- architecture before implementation
- small reviewable changes
- automated regression testing
- native validation when appropriate
- independent review
- Git branches and pull requests
- documentation synchronized with implementation

AI-generated code remains subject to the same review and validation standards as any other implementation.
